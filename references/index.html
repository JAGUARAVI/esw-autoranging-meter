04 · Two measurement physics

Oscillator for small C, RC step for large C

Mode A · small C

Relaxation oscillator

The SN74LVC1G34 drives a square wave through the selected range resistor into V_cap. COMP1 on PA1 compares V_cap with an internal threshold (hysteresis via DAC or built-in). Each crossing flips PB0. The period is counted by a timer.

f = 1 / [ 2 R C ln( (Vdrv − V_L) / (Vdrv − V_H) ) ]

With symmetric 50 % thresholds this collapses to f ≈ 0.721 / (R C). Invert: C ≈ 0.721 / (R f) − C_stray.

Use 100 kΩ for pF–nF ceramics. Frequency stays roughly 70 Hz – 70 kHz, which TIM2 loves. COMP1 is the right sensor — the ADC sampling cap would eat picofarads.

Mode B · large C

RC step tracking

PB0 is held high. V_cap rises as Vdrv (1 − e−t/RC). PA0 is sampled with ADC + DMA. Firmware finds τ from a 63 % point or a curve fit.

V(t) = Vdrv (1 − e−t / RC)  ⇒  C = −t / [ R ln(1 − V/Vdrv) ]

Hand-off from oscillator when f drops below ~50 Hz (C ≳ 100 nF on the 100 kΩ range). Drop to 1 kΩ then 100 Ω as C grows. The buffer exists specifically so the 100 Ω range can pull 33 mA.

05 · Why the parts exist

Equations the hardware is built around

Boost math

VOUT = 0.6 (1 + R1/R2)

R1 = 150 kΩ, R2 = 4.7 kΩ → 19.75 V. This is the raw rail, later dropped across the Darlington.

Bias gain

V_BIAS = 6.6 × 0.909 × V_DAC

Divider 10k/100k then non-inverting 56k/10k. Maps 0–3.3 V → 0–19.8 V.

Current limit

I_LIM = Vbe / 10 Ω ≈ 65 mA

2N2222 Vbe across the emitter sense resistor. Hardware, not firmware.

Series C_block

C_eq = C_b C_d / (C_b + C_d)

For 470 nF DUT, C_b = 1000 µF → error ~0.05 %. For 1000 µF DUT, C_eq = 500 µF — correct in firmware.

Oscillator

C = 0.721 / (R f) − C_stray

Assumes 50 % thresholds. Include buffer Zo + mux Ron in R. C_stray ~ few pF + ADC/COMP pin.

Displacement

Q = C_block ΔV ≈ 20 mC

Pre-charge of N_DUT by 20 V forces this charge through C_block. SSR3 + 1 Ω must swallow it.

08 · Firmware handshake

Make the hardware function automatically

The circuit is designed so GPIO timing, not extra analog ICs, sequences the dangerous edges. This is the state machine the timers and COMP1 should implement.

Recommended state machine

  1. IDLE — all SSRs off, MUX CH4 (NC), PB0 low. DUT may be inserted.
  2. DISCHARGE — PB8 on for ≥ 5τ of the previous C. Confirm V_DUT ~ 0 if you have a spare ADC divider.
  3. PRE- CHARGE — PB10 on (SSR3 clamps V_cap, SSR1 charges N_DUT through 10 Ω). Wait until I_sense dies out. DAC already sits at the requested V_BIAS.
  4. ISOLATE — PB10 off. N_DUT remains at bias through 1 MΩ. V_cap is free. BAT54S still watching.
  5. RANGE — set A0/A1. Start in 100 kΩ. If oscillator < 50 Hz or RC τ too long, drop a range.
  6. MEASURE OSC — enable COMP1 + TIM capture, toggle PB0 (or let COMP steer a timer output). Average N periods, compute C.
  7. MEASURE RC — hold PB0 high, ADC DMA at a known Fs, fit τ, compute C. Discharge V_cap between repeats.
  8. DISCHARGE — PB8 on. Then IDLE. Never unclip a biased DUT.

Peripheral plan

DAC1 CH2 (PA5) — 12-bit, buffered, slow software updates. 0 code = 0 V bias.

COMP1 (PA1) — INP = PA1, INM = DAC1 CH1 or VREFBUF/2, hysteresis on. Output to TIM2 input capture / EXTI that flips PB0.

TIM2 — period measurement in oscillator mode; timebase for ADC triggers in RC-step mode.

ADC1 (PA0) — 12-bit, DMA circular, 1–4 µs sample. Ignore the first sample after a mux change (charge injection).

GPIOs — PB10 and PB8 as push-pull with the 330 Ω LED resistors. Never PWM them; PhotoMOS need DC LED current.
